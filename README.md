# FRUTÊ Delivery — pedidos no Firebase

Consulte ATIVAR-PEDIDOS.md para instalar esta versão.

O projeto mantém todos os arquivos na raiz, sem subpastas. Inclui cardápio, fotos pelo painel, carrinho, perfil sem CEP, setores com taxa, contato WhatsApp, envio de pedidos e acompanhamento no painel e no navegador do cliente.

Administrador: e-mail e senha com autorização admins/UID enabled=true. Cliente: identidade anônima automática, sem formulário de login. Publique as regras atualizadas deste pacote e habilite o provedor Anônimo antes do uso.

Os pagamentos não são cobrados nem confirmados pelo aplicativo. Pedidos recebidos não significam pagamentos aprovados. Não existem integração Pix e relatórios de vendas pagas nesta etapa.

Verificação: 13 testes locais e 16 testes das regras no emulador passaram. O projeto Firebase real e a publicação GitHub não foram alterados automaticamente. Faça um pedido de teste antes de usar na loja.
