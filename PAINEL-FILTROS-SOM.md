# Organização dos pedidos e aviso sonoro

1. Envie todos os arquivos deste pacote extraídos à raiz do GitHub, substituindo os anteriores.
2. Aguarde a publicação e abra admin.html com Ctrl+Shift+R.
3. Use os filtros Todos, Novos, Em preparação, Saiu para entrega, Entregues e Cancelados. Os números mostram a quantidade de cada status entre os 100 pedidos carregados.
4. Busque por nome, telefone, identificador de pedido, produto ou setor. A busca combina com o filtro selecionado e ignora acentos.
5. Clique em Ativar som de novos pedidos. Você ouvirá um toque de teste. Deixe o painel aberto e o aparelho com volume para receber o toque de cada chegada de novo pedido. Clique novamente para desativar.

O som não toca para pedidos antigos ao abrir o painel nem a cada alteração de status. O aviso visual destaca os novos pedidos e permite abrir o filtro Novos mesmo quando você está consultando outro status.

O navegador pode suspender áudio em segundo plano. O aviso não funciona com o painel fechado e não é push. Ao reabrir o painel ou entrar novamente, ative o som de novo. O toque e os avisos não representam confirmação de pagamento.

Esta atualização não altera preços, taxas, dados do Firebase nem regras de segurança. Não precisa republicar regras. O acesso continua apenas por e-mail e senha do administrador autorizado.

23 testes locais passaram, incluindo filtros combinados, busca por telefone formatado e contagem por andamento. A reprodução do som deve ser conferida no seu aparelho com o botão de teste. Esta entrega não publicou alterações no GitHub automaticamente.
